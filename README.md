# Ferrata Time

A Garmin Connect IQ watch face and watch app for climbing via ferratas. Pick a real route, and the
watch shows its outline with your position on it, metres climbed of the total, rests and hard sections
ahead, and the time left.

Status: design phase. There is no Monkey C code yet. The design record and an interactive browser demo
follow in `design/`.

Images and fonts are stored with [Git LFS](https://git-lfs.com): install it (`brew install git-lfs`,
then `git lfs install`) before cloning.

Tracked in this repository, and in the family's umbrella as
[`wkusnierczyk/garmin-watch-faces#42`](https://github.com/wkusnierczyk/garmin-watch-faces/issues/42).
